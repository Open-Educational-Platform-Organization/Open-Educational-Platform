# English

## Idea
Create an open educational platform with gamification elements, where users can learn, create educational content, and contribute to the development of the platform.

## Key Features (Draft)
* **Gamification:** Level system, XP rewards for completing lessons, and achievement badges.
* **Content Co-creation:** Users can design courses, submit quizzes, and review other materials.
* **Open Source Contribution:** Integrated pathways for developers to improve the core platform.

# Українська

## Ідея
Створити відкриту освітню платформу з елементами гейміфікації, де користувачі можуть навчатися, створювати освітній контент і брати участь у розвитку платформи.

## Ключові можливості (Чернетка)
* **Гейміфікація:** Система рівнів, отримання досвіду (XP) за виконані завдання, бали та бейджі за досягнення.
* **Спільне створення контенту:** Користувачі можуть створювати власні курси, додавати тести та рецензувати чужі матеріали.
* **Внесок в Open Source:** Чіткі інструкції для розробників-початківців, які хочуть покращувати код самої платформи.
